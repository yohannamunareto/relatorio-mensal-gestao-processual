# Relatório mensal de gestão processual

Indicadores mensais do sistema de gestão de processos do escritório, entregues de forma automatizada à gestão.

> **Confidencialidade:** esta ferramenta foi construída para uso interno de um escritório de advocacia. O código e os dados não são públicos. Este repositório documenta o problema, a solução e os resultados, sem nomes de clientes, partes ou processos.

## Problema

Os indicadores do sistema de gestão processual eram levantados e montados todo mês no Power BI, para depois virar apresentação.

## Como funciona

- Defini, junto com uma empresa de jurimetria, todos os filtros e dados a serem levantados.
- Indicadores: fichas criadas e encerradas, tipos de demanda, fase dos processos, matérias predominantes, fichas com preenchimento incompleto, carga por advogado, eventos atrasados e média de dias de atraso.
- O relatório é gerado e entregue de forma automatizada, em PowerPoint.

## Ferramentas

Sistema de gestão processual, IA e parceria com empresa de jurimetria. Antes, Power BI.

## Resultados

- A entrega mensal deixou de depender de montagem manual no Power BI.
- Acompanha de 60 a 81 novas fichas por mês, em 8 grupos de indicadores.
